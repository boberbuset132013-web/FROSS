# Передача знаний FROSS: учитель → ученик

## Как устроено обучение

В репозитории есть два набора примеров:

- `data/fross_corpus.jsonl` — 328 исходных диалоговых примеров FROSS.
- `data/fross_teacher_corpus.jsonl` — 82 подготовленных примера, созданных учителем для начального переноса полезных ответов и навыков.

Перед запуском Transformer программа проверяет строки, объединяет наборы и убирает точные повторы пользовательских запросов. Учебный набор создаётся в локальной папке `.fross-local-training/`.

Это **передача знаний через синтетические текстовые примеры** (supervised fine-tuning на данных учителя), а не копирование весов: модель-учитель отвечает на вопросы, а FROSS учится предсказывать текст на этих парах. Текущий FROSS инициализируется и обучается со своими весами. Учитель не вызывается во время обучения FROSS и не требуется для ответов после обучения.

## Дополнительные данные от локальной модели-учителя (необязательно)

Если хочешь расширить корпус, можно использовать локальную модель через Ollama. Она работает на этом же ПК и предоставляет локальный API на `http://localhost:11434`; запросы генерации не отправляются этим скриптом в облачный LLM API. См. [официальную документацию Ollama для Windows](https://ollama.readthedocs.io/en/windows/) и [API генерации](https://docs.ollama.com/api/generate).

1. Установи Ollama для Windows и запусти её.
2. В терминале установи локальную instruct-модель, например: `ollama pull qwen2.5:3b`. Понадобится свободное место на диске; генерация на CPU может работать медленно. Можно указать другую модель, если она уже установлена.
3. В распакованной папке репозитория запусти `training/windows/TEACH_FROSS.bat`. Чтобы выбрать другую установленную модель, передай её имя аргументом: `TEACH_FROSS.bat qwen2.5:3b`.
4. Скрипт запросит новые вопросы и ответы у локального учителя, проверит формат, отфильтрует дубли и добавит примеры в `data/fross_teacher_corpus.jsonl`. Учитель не обучается и его веса в FROSS не копируются.

Дополнительный учитель необязателен: начальные 82 teacher-примера уже есть в репозитории, поэтому можно сразу начать обучение FROSS. Счётчик примеров — не гарантия качества: ответы учителя стоит проверять, особенно примеры кода и фактические утверждения.

## Обучить только FROSS

1. Запусти `training/windows/START_TRAIN_600.bat`. Скрипт готовит общий корпус и обучает FROSS с нуля до 600 шагов.
2. После успешного завершения запусти `training/windows/CONTINUE_TO_3000.bat`. Он восстанавливает последнее состояние FROSS, включая состояние AdamW и генераторов случайных чисел, и продолжает до 3000 шагов суммарно.
3. Проверь модель через `training/windows/CHECK_TRAINING.bat`.

После первого этапа **не изменяй** `data/fross_corpus.jsonl` или `data/fross_teacher_corpus.jsonl` до продолжения: тренер сверяет SHA-256 общего корпуса, сид и расписание, чтобы не продолжить обучение на других данных случайно. Локальные веса сохраняются в `.fross-local-training/fross-transformer.pt`; они не загружаются автоматически в GitHub или Hostless.

## Важное ограничение

Размер FROSS гораздо меньше типичной модели-учителя. Дистилляция помогает передать некоторые закономерности и примеры, но не переносит все знания, параметры или способности учителя. 3000 шагов сами по себе не гарантируют беглые ответы. Для оценки нужны отложенные вопросы, разнообразный корпус и проверка фактической точности.
