# Локальное обучение FROSS Brain 1.5 на Windows

Здесь обучается FROSS — собственная нейросеть проекта. Корпус содержит исходные диалоги и подготовленные примеры учителя. Для старта Brain 1.5 скрипт использует совместимые внутренние слои предыдущего Brain 1.4, но не копирует старые токеновые эмбеддинги: у нового Unigram другие ID и таблица токенов обучается заново.

## Запуск

1. Открой репозиторий **boberbuset132013-web/FROSS** на GitHub.
2. Нажми **Code → Download ZIP**, распакуй весь репозиторий в обычную папку. Не запускай BAT-файлы внутри окна просмотра ZIP.
3. Открой папку `training/windows`.
4. Необязательно: если нужны дополнительные примеры от отдельной локальной модели-учителя, смотри [инструкцию по дистилляции](../distillation/README_RU.md) и запусти `TEACH_FROSS.bat`. Начальный набор учителя уже есть — этот шаг можно пропустить.
5. Запусти `START_TRAIN_600.bat`. Скрипт создаст отдельное Python-окружение, установит CPU-версию PyTorch и SentencePiece, объединит два корпуса и выполнит первые 600 шагов обучения FROSS Brain 1.5. Цель архитектуры: словарь 30 000 токенов, контекст 500 токенов и 8,97 млн параметров (7 слоёв, 6 attention heads, embedding 192).
6. После успешного завершения запусти `CONTINUE_TO_3000.bat`. Он **продолжит с сохранённого состояния до суммарных 3000 шагов**, а не добавит ещё 3000 сверху. После этапа автоматически появится компактный файл для загрузки на сайт.
7. Для проверки чекпоинта запусти `CHECK_TRAINING.bat`.

## Как работает передача знаний

- Учитель создаёт текстовые пары «вопрос — качественный ответ». Подготовленный набор находится в `data/fross_teacher_corpus.jsonl`.
- `training/distillation/prepare_corpus.py` проверяет JSONL, непустые поля и историю диалога, объединяет записи и убирает дубли по вопросу/контексту.
- Brain 1.5 начинает с совместимых attention/feed-forward блоков и нормализации Brain 1.4; позиционные эмбеддинги копируются для первых 320 позиций.
- Новые 25 000 токеновых эмбеддингов остаются отдельно и инициализируются заново, потому что ID старого BPE-словаря не совпадают с ID SentencePiece Unigram.
- После инициализации обучение обновляет все параметры Brain 1.5 на собственном корпусе; внешний учитель после подготовки текстовых примеров не нужен.

## Что сохраняется

- Общий подготовленный корпус: `.fross-brain15-training/training-corpus.jsonl`
- Полный обучающий чекпоинт для продолжения: `.fross-brain15-training/fross-transformer-1.5-training.pt`
- Компактная модель для FROSS → Настройки → Загрузить модель: `.fross-brain15-training/fross-transformer-upload.pt`
- Логи этапов: `.fross-brain15-training/logs/`
- Отдельное окружение Python: `.venv-training/`

Файлы Brain 1.5 хранятся отдельно от старых экспериментов в `.fross-brain15-training`; старый Brain 1.4 и прежние локальные чекпоинты не перезаписываются. Полный чекпоинт включает состояние оптимизатора, чтобы можно было продолжить обучение. Компактный файл содержит только необходимые для работы модели данные и не включает состояние оптимизатора.

## Важные условия

- Используй те же файлы `data/fross_corpus.jsonl` и `data/fross_teacher_corpus.jsonl` для обоих этапов. Тренер проверяет SHA-256 общего корпуса, сид и расписание обучения перед продолжением.
- Не добавляй новые примеры учителя между этапами 600 и 3000. Сначала закончи цикл обучения; после изменения корпуса начни новую последовательность или сохрани отдельную копию эксперимента.
- Не удаляй полный чекпоинт между этапами. Если этап 600 завершился ошибкой, сначала изучи лог и сохрани файл, а не начинай новый запуск поверх него. Для сайта используй только компактный `fross-transformer-upload.pt`.
- Не закрывай окно во время обучения. Время зависит от процессора и свободной памяти; на медленном ПК обучение может занять долгое время.
- Увеличение количества шагов само по себе не гарантирует, что ответы станут грамотнее. Качество зависит от точности и разнообразия примеров, размера модели и независимой проверки.
- Результат остаётся на твоём компьютере. Чтобы использовать новые веса на сайте/Hostless, нужно отдельно проверить совместимость и развернуть модель; локальные BAT-файлы ничего не публикуют автоматически.

## Устранение проблем

- Если Windows блокирует BAT, запускай файлы только из распакованного тобой репозитория. Внутри используется PowerShell для запуска локального Python.
- Если PowerShell снова выдаёт синтаксическую ошибку, скачай свежий ASCII-only файл [TRAIN_FROSS.ps1](https://raw.githubusercontent.com/boberbuset132013-web/FROSS/main/training/windows/TRAIN_FROSS.ps1) и замени старый.
- Если установка PyTorch завершается ошибкой, проверь интернет и доступность `https://download.pytorch.org/whl/cpu`.
- Если локальное обучение учителем не работает, проверь, что Ollama запущена и указанное имя модели действительно установлено. Это необязательный шаг; встроенные teacher-примеры можно обучать без Ollama.
- Если продолжение отказывается работать, корпус мог измениться или параметры не совпасть. Не редактируй чекпоинт вручную; сохрани лог из `.fross-brain15-training/logs/` для диагностики. Если SentencePiece не смог создать ровно 30 000 токенов, добавь больше разнообразных примеров в корпус и начни новую отдельную последовательность обучения.
