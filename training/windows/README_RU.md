# Локальное обучение FROSS Brain 1.4 на Windows

Эти скрипты обучают собственный FROSS Transformer на твоём ПК, без облачного LLM API. Веса сохраняются локально — сайт и сервис Hostless автоматически не меняются.

## Запуск

1. Открой репозиторий **boberbuset132013-web/FROSS** на GitHub.
2. Нажми **Code → Download ZIP**, распакуй весь репозиторий в обычную папку. Не запускай скрипты внутри окна просмотра ZIP.
3. Открой папку `training/windows`.
4. Запусти `START_TRAIN_600.bat` и дождись окончания. Скрипт создаст отдельное Python-окружение, установит PyTorch CPU и выполнит первые 600 шагов.
5. После успешного завершения запусти `CONTINUE_TO_3000.bat`. Он **продолжит с сохранённого состояния до суммарных 3000 шагов**, а не добавит ещё 3000 сверху.
6. Чтобы проверить сохранённую модель, запусти `CHECK_TRAINING.bat`.

## Что сохраняется

- Чекпоинт: `.fross-local-training/fross-transformer.pt`
- Логи этапов: `.fross-local-training/logs/`
- Отдельное окружение Python: `.venv-training/`

Чекпоинт и окружение исключены из Git — большие бинарные веса не будут случайно отправлены в репозиторий. Скрипт не перезаписывает уже существующий первый чекпоинт.

## Важные условия

- Используй один и тот же `data/fross_corpus.jsonl` для обоих этапов. Код проверяет хеш корпуса, сид и расписание обучения перед продолжением.
- Не удаляй чекпоинт между этапами. Если этап 600 завершился ошибкой, сначала посмотри лог, а не начинай поверх него новый запуск.
- Не закрывай окно во время обучения. Время зависит от процессора и свободной памяти; на медленном ПК обучение может занять долгое время.
- Не обещается, что увеличение числа шагов само по себе сделает ответы грамотными: качество зависит также от объёма и разнообразия корпуса.
- Результат остаётся на твоём компьютере. Чтобы использовать новые веса на сайте/Hostless, потребуется отдельно проверить совместимость и развернуть модель; эти скрипты ничего не загружают в интернет, кроме установки PyTorch.

## Устранение проблем

- Если Windows блокирует `.bat`, запускай только файлы из распакованного тобой репозитория. Внутри используется PowerShell для запуска локального Python.
- Если появится ошибка установки PyTorch, проверь интернет и доступность `https://download.pytorch.org/whl/cpu`.
- Если продолжение отказывается работать, обычно это означает, что чекпоинт старого формата, корпус изменился или указаны другие параметры. Не меняй файл модели вручную; сохрани лог из `.fross-local-training/logs/` для диагностики.
