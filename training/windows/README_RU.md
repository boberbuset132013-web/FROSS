# Локальное обучение FROSS Brain 1.4 на Windows

Здесь обучается только FROSS — собственная маленькая нейросеть проекта. Корпус сейчас содержит 328 исходных диалогов и 281 подготовленный пример учителя; число примеров может увеличиваться. Учитель передаёт ответы как текстовые примеры; веса другой модели в FROSS не копируются.

## Запуск

1. Открой репозиторий **boberbuset132013-web/FROSS** на GitHub.
2. Нажми **Code → Download ZIP**, распакуй весь репозиторий в обычную папку. Не запускай BAT-файлы внутри окна просмотра ZIP.
3. Открой папку `training/windows`.
4. Необязательно: если нужны дополнительные примеры от отдельной локальной модели-учителя, смотри [инструкцию по дистилляции](../distillation/README_RU.md) и запусти `TEACH_FROSS.bat`. Начальный набор учителя уже есть — этот шаг можно пропустить.
5. Запусти `START_TRAIN_600.bat`. Скрипт создаст отдельное Python-окружение, установит CPU-версию PyTorch, проверит и объединит два корпуса и выполнит первые 600 шагов обучения FROSS.
6. После успешного завершения запусти `CONTINUE_TO_3000.bat`. Он **продолжит с сохранённого состояния до суммарных 3000 шагов**, а не добавит ещё 3000 сверху.
7. Для проверки чекпоинта запусти `CHECK_TRAINING.bat`.

## Как работает передача знаний

- Учитель создаёт текстовые пары «вопрос — качественный ответ». Подготовленный набор находится в `data/fross_teacher_corpus.jsonl`.
- `training/distillation/prepare_corpus.py` проверяет JSONL, непустые поля и историю диалога, объединяет записи и убирает дубли по вопросу/контексту.
- FROSS обучается предсказывать текст на этих примерах, начиная с собственных случайно инициализированных весов.
- После сохранения примеров учитель больше не нужен. Во время этапов 600 и 3000 шагов обучается только FROSS.

## Что сохраняется

- Общий подготовленный корпус: `.fross-local-training/training-corpus.jsonl`
- Чекпоинт FROSS: `.fross-local-training/fross-transformer.pt`
- Логи этапов: `.fross-local-training/logs/`
- Отдельное окружение Python: `.venv-training/`

Чекпоинт и окружение исключены из Git — большие бинарные веса не отправляются в репозиторий автоматически. Скрипт не перезаписывает уже существующий первый чекпоинт.

## Важные условия

- Используй те же файлы `data/fross_corpus.jsonl` и `data/fross_teacher_corpus.jsonl` для обоих этапов. Тренер проверяет SHA-256 общего корпуса, сид и расписание обучения перед продолжением.
- Не добавляй новые примеры учителя между этапами 600 и 3000. Сначала закончи цикл обучения; после изменения корпуса начни новую последовательность или сохрани отдельную копию эксперимента.
- Не удаляй чекпоинт между этапами. Если этап 600 завершился ошибкой, сначала изучи лог и сохрани файл, а не начинай новый запуск поверх него.
- Не закрывай окно во время обучения. Время зависит от процессора и свободной памяти; на медленном ПК обучение может занять долгое время.
- Увеличение количества шагов само по себе не гарантирует, что ответы станут грамотнее. Качество зависит от точности и разнообразия примеров, размера модели и независимой проверки.
- Результат остаётся на твоём компьютере. Чтобы использовать новые веса на сайте/Hostless, нужно отдельно проверить совместимость и развернуть модель; локальные BAT-файлы ничего не публикуют автоматически.

## Устранение проблем

- Если Windows блокирует BAT, запускай файлы только из распакованного тобой репозитория. Внутри используется PowerShell для запуска локального Python.
- Если PowerShell снова выдаёт синтаксическую ошибку, скачай свежий ASCII-only файл [TRAIN_FROSS.ps1](https://raw.githubusercontent.com/boberbuset132013-web/FROSS/main/training/windows/TRAIN_FROSS.ps1) и замени старый.
- Если установка PyTorch завершается ошибкой, проверь интернет и доступность `https://download.pytorch.org/whl/cpu`.
- Если локальное обучение учителем не работает, проверь, что Ollama запущена и указанное имя модели действительно установлено. Это необязательный шаг; встроенные teacher-примеры можно обучать без Ollama.
- Если продолжение отказывается работать, корпус мог измениться или параметры не совпасть. Не редактируй чекпоинт вручную; сохрани лог из `.fross-local-training/logs/` для диагностики.
