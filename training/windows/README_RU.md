# FROSS Brain 1.6 — локальное обучение на Windows

Brain 1.6 — собственная decoder-only Transformer-модель FROSS. Целевая конфигурация: **64 819 040 параметров**, словарь SentencePiece Unigram на **8 000 токенов**, контекст **4 096 токенов**, план обучения **100 000 шагов**.

Brain 1.5 сохраняется как отдельная резервная модель. У неё другая ширина и число attention heads, поэтому её веса нельзя напрямую продолжить в Brain 1.6. Новая архитектура начинает с собственной инициализации; старые файлы не перезаписываются.

## Запуск

1. Открой репозиторий **boberbuset132013-web/FROSS** на GitHub.
2. Нажми **Code → Download ZIP** и распакуй весь репозиторий в обычную папку.
3. Открой PowerShell в папке `training/windows`.
4. При необходимости подготовь дополнительные текстовые примеры учителя через [инструкцию дистилляции](../distillation/README_RU.md). Обучающий корпус должен содержать много разнообразных качественных примеров; 100 000 шагов на маленьком повторяющемся наборе могут привести к переобучению.
5. Запусти этапы по порядку:

```powershell
.\TRAIN_FROSS.ps1 -Stage 25000
.\TRAIN_FROSS.ps1 -Stage 50000
.\TRAIN_FROSS.ps1 -Stage 75000
.\TRAIN_FROSS.ps1 -Stage 100000
.\TRAIN_FROSS.ps1 -Stage check
```

Каждый этап задаёт **суммарную** цель, а не добавляет указанное число шагов сверху. Продолжение использует сохранённые веса, состояние AdamW и генераторы случайных чисел. Между этапами не меняй обучающий корпус.

## Как устроено обучение

- Данные объединяются из `data/fross_corpus.jsonl` и `data/fross_teacher_corpus.jsonl`; дубликаты удаляются.
- SentencePiece Unigram строит новый словарь на 8 000 токенов. Токеновые embedding-матрицы Brain 1.5 не копируются.
- Архитектура: 18 слоёв, 8 attention heads, embedding 520, tied embeddings.
- Контекст 4 096 токенов. Attention считается небольшими query-блоками; activation/gradient checkpointing уменьшают пиковую память ценой дополнительного времени.
- После 100 000 шагов создаётся отдельный int8 inference-файл. Полный checkpoint с состоянием оптимизатора сохраняется для продолжения обучения.

## Файлы

- Корпус: `.fross-brain16-training/training-corpus.jsonl`
- Полная обучающая контрольная точка: `.fross-brain16-training/fross-transformer-1.6-64m-training.pt`
- Компактная модель для FROSS → Настройки → Загрузить модель: `.fross-brain16-training/fross-transformer-1.6-64m-int8.pt`
- Логи: `.fross-brain16-training/logs/`
- Изолированное окружение Python: `.venv-training/`

## Важные условия

- Скрипт использует CPU-сборку PyTorch. На CPU и особенно при контексте 4 096 шаги могут выполняться долго.
- Память нужна не только под сами веса: обучение хранит градиенты, состояние оптимизатора и промежуточные вычисления. Если система завершает Python из-за нехватки памяти, не удаляй checkpoint — сохрани лог и проверь доступную RAM.
- Не меняй корпус, seed или параметры архитектуры между этапами. Проверка продолжения сравнивает SHA-256 корпуса и метаданные checkpoint.
- Не удаляй полный обучающий checkpoint после создания int8-файла. Для продолжения нужен именно полный файл.
- 100 000 шагов не являются автоматической гарантией умного диалога. Результат проверяется по validation loss и отдельным тестам диалога, кода, продолжения беседы и повторов. Корпус должен быть достаточно большим, чистым и разнообразным.
- Локальные BAT/PowerShell-команды не запускают серверное обучение и не публикуют модель автоматически. Для сайта загрузи компактный int8-файл после проверки.

## Если возникла ошибка

- Сохрани полный текст соответствующего лога из `.fross-brain16-training/logs/`.
- Не запускай первый этап повторно поверх существующей контрольной точки.
- Если продолжение сообщает о несовпадении корпуса, верни исходные JSONL-файлы из того же набора данных; не редактируй checkpoint вручную.
- Если SentencePiece не может создать ровно 8 000 токенов, расширь корпус новыми уникальными текстами на поддерживаемых языках и начни отдельный новый цикл.
