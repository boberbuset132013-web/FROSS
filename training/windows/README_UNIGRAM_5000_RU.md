# FROSS 1.5 — обучение SentencePiece Unigram до 5000 шагов

## Запуск на Windows

1. Открой GitHub-репозиторий `boberbuset132013-web/FROSS`, нажми **Code → Download ZIP** и распакуй весь архив.
2. Открой папку `training/windows`.
3. Дважды нажми `START_FROSS_UNIGRAM_5000.bat`.
4. Не закрывай окно во время обучения. При первом запуске скрипт создаст отдельное Python-окружение, установит PyTorch CPU и SentencePiece, проверит корпус и запустит обучение.
5. Скрипт сначала обучит модель до 600 шагов, затем автоматически продолжит её до **5000 суммарных шагов**. В обоих этапах используются одинаковые корпус, сид и расписание.
6. После завершения проверь метрики и пример ответа в консоли и логах.

## Параметры эксперимента

- Токенизатор: SentencePiece Unigram.
- Целевой словарь: 20 000 токенов. Реальный размер может быть меньше — смотри `vocab_size` и `vocab_target_reached` в итоговой статистике.
- Обучение: 5000 суммарных шагов, CPU, batch size 4, context/block size 320.
- Архитектура: текущая архитектура FROSS 1.5; при полном словаре 20 000 параметров ожидается около 6.6 млн. Если токенизатор сформирует меньший словарь, число параметров будет ниже.
- Чекпоинт эксперимента: `.fross-local-training/unigram-20k-5000/fross-transformer.pt`.
- Логи: `.fross-local-training/unigram-20k-5000/logs/`.
- Отдельное окружение: `.venv-unigram-training/`.

## Безопасность и возобновление

- Текущий чекпоинт FROSS 1.4 и старые локальные эксперименты не перезаписываются: используется отдельная папка.
- Если окно закроется после сохранения этапа 600, повторный запуск BAT продолжит обучение с 600 шагов. Если второй этап прервётся до сохранения итогового чекпоинта, он начнётся снова с последнего сохранённого этапа.
- Не изменяй файлы корпуса между этапами: код проверяет SHA-256 перед продолжением.
- Чекпоинт остаётся на твоём компьютере. Скрипт не загружает модель в GitHub Releases, Hostless или на рабочий сайт автоматически.
- 5000 шагов не гарантируют хороших ответов. После обучения проверь связность, повторения и ответы на независимом наборе вопросов. Нынешний корпус небольшой для модели такого размера; для заметного улучшения качества нужно постепенно добавлять много разнообразных качественных примеров.

## Если что-то не работает

Сохрани сообщение об ошибке и соответствующий лог из `.fross-local-training/unigram-20k-5000/logs/`. Не удаляй чекпоинт и не запускай новый эксперимент поверх старого.
